Table
Fitur minimal yang wajib ada pada setiap tabel:
1 Sort per kolom — setiap header kolom data harus bisa diklik ↑↓
2 General Search — search box di kanan atas, mencari semua kolom sekaligus
3 Pagination — navigasi halaman + rows per page menggunakan Pagination.vue
Tabel tanpa salah satu dari ketiganya dianggap belum sesuai standar.

Kode Referensi
<!-- Toolbar: judul + search box -->
<div class="flex items-center justify-between mb-3">
  <h3 class="text-[15px] font-semibold">Daftar Data</h3>
  <div class="relative">
    <!-- icon search -->
    <input v-model="searchQuery" type="search" placeholder="Cari..."
           class="pl-9 pr-4 py-2 text-sm bg-gray-50 border border-gray-300
                  rounded-lg focus:ring-2 focus:border-blue-500 outline-none w-64" />
  </div>
</div>

<!-- Table wrapper -->
<div class="overflow-x-auto rounded-xl border border-gray-200">
  <table class="w-full text-sm text-left">
    <thead class="bg-gray-50">
      <tr>
        <!-- Kolom data: wajib ada sort -->
        <th class="px-4 py-2 text-xs font-semibold uppercase tracking-wide
                   cursor-pointer" @click="sort('nama')">
          Nama <span>↕</span>
        </th>
        <!-- Kolom aksi: tidak perlu sort -->
        <th class="px-4 py-2 text-xs font-semibold uppercase tracking-wide">
          Aksi
        </th>
      </tr>
    </thead>
    <tbody>
      <tr class="odd:bg-white even:bg-gray-50 border-b border-gray-200 hover:bg-blue-50">
        <td class="px-5 py-2.5">Data</td>
        <td class="px-5 py-2.5">
          <button class="text-xs px-3 py-1 rounded-full ...">Edit</button>
        </td>
      </tr>
    </tbody>
  </table>
</div>
✅
Kolom "Aksi" tidak perlu sort — set filterable: false dan jangan beri ikon ↕
❌
Jangan buat tabel baru tanpa sort & search — selalu pakai TableSearch.vue
